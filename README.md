# Модель компетенций управленца в здравоохранении

Первая презентационная страница для визуализации модели компетенций: цель модели + 8 доменов.

## Доменная структура

1. Отраслевая и системная навигация
2. Стратегическое управление и результат
3. Операционное управление и эффективность
4. Качество, безопасность, пациентоцентричность
5. Ресурсы и устойчивость
6. Люди, команды, организационная среда
7. Коммуникации и влияние
8. Цифровое управление, данные, ИБ

Сквозные уровни: линейный руководитель → руководитель МО / направления → региональный уровень → федеральный / страновой / страховой уровень.
